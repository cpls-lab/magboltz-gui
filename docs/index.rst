Magboltz-GUI Documentation
==========================

`Magboltz-GUI` is a Python/Qt desktop frontend for preparing Magboltz inputs,
running local simulations, and exporting or visualising the resulting transport
quantities.

This documentation is split into short narrative guides plus API reference
pages for the Python modules that define the data model, parsers, export layer,
and runtime helpers.
